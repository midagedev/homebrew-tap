# midagedev/homebrew-tap

```sh
brew install midagedev/tap/gadak
```

[gadak](https://github.com/midagedev/gadak) — a local SQLite mirror of your
Jira issues and Confluence pages, with a web UI, a TUI, and a SQL/CLI
surface for agents.

`brew install midagedev/tap/scry` is deprecated; that name was retired.

Formulae here are updated by the release pipeline; the checksums come from each
release's own `checksums.txt`.
