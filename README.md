# midagedev/homebrew-tap

```sh
brew install midagedev/tap/scry
```

[scry](https://github.com/midagedev/scry) — a local SQLite mirror of your Jira
issues, with a web UI, a TUI, and a SQL/CLI surface for agents.

Formulae here are updated by the release pipeline; the checksums come from each
release's own `checksums.txt`.
